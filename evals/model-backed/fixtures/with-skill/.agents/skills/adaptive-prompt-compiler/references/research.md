# Research Prompts

Use these rules only when the target must research or synthesize evidence.

- Define the research question and decision the evidence must support.
- Prefer primary/high-authority sources; use fresh sources when the topic changes over time.
- Preserve provenance and distinguish source facts from inference.
- Seek contradictory evidence when it could change the conclusion.
- Deduplicate sources and keep only decision-relevant evidence in active context.
- Mark uncertainty instead of filling unsupported gaps.
- Make the final output separate findings, evidence, uncertainty, and recommendation when appropriate.
